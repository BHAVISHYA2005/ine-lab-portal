# UI/UX Pro Max

Design and implement a calm, focused interface for the INE Lab Submission Portal.

## Visual direction

- Use a calm interface aesthetic: generous whitespace, muted accent colors, and no visual theatrics.
- Use a Bento grid layout for the labs dashboard, with cards of varying sizes arranged using CSS Grid.
- Use micro-interactions that explain rather than perform: loading skeletons, subtle hover lifts, and progress transitions.
- Dark mode is the default; provide light mode as an option.
- Use Inter or Geist for UI typography and JetBrains Mono for code and lab content.
- Do not use generic AI landing-page patterns: no purple gradients and no floating 3D blobs.

## Accessibility and machine experience

- Treat accessibility as infrastructure and meet WCAG AA minimums.
- Keep focus rings visible and ensure all interactions are keyboard-navigable.
- Prefer semantic HTML, descriptive ARIA labels where needed, and structured data that supports machine experience (MX).
- Preserve clear hierarchy, readable contrast, predictable interaction states, and reduced-motion compatibility.
